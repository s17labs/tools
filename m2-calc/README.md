# m² Calc

[Explore the Live Tool »](https://s17labs.github.io/tools/m2-calc)

A fast, mobile-friendly construction cost calculator. Enter your area, rate per m², and optional VAT and waste factor — get an instant cost breakdown. No server, no tracking, runs entirely in the browser.

## Features

* **Three Input Methods**: Enter area directly, calculate from Length × Width, or add multiple rooms with individual dimensions.
* **Multi-Room Support**: Add and name multiple areas — totals are calculated automatically across all rooms.
* **Waste Factor**: Account for material waste by adding a percentage on top of the net area.
* **VAT Support**: Optionally include a VAT rate — the result card shows net cost, VAT amount, and total separately.
* **Multilingual**: Available in English, Slovak, and German.
* **Dark / Light / System Theme**: Follows your system preference or switch manually.

## Technical Details

Built using vanilla HTML5, CSS3, and JavaScript, utilizing:
- **Barlow & Barlow Condensed**: Clean, construction-site-ready typography via Google Fonts.
- **Cookie-based Preferences**: Language and theme choices are persisted locally via cookies — no backend needed.
- **Zero Dependencies**: No frameworks, no libraries, no build step.

## Usage
Simply open the `index.html` file in any modern browser or visit the [live page](https://s17labs.github.io/tools/m2-calc).
